# 💳 Tarjeta digital · jonadevp

Tarjeta de presentación digital para ofrecer landing pages, portafolios y blogs a negocios. Se comparte con un solo link por WhatsApp y se ve bien en celular. 📱

🌐 **Sitio:** [jonadevp.com](https://jonadevp.com)

## ✨ Qué incluye

- 🚀 Servicios: landing page, portafolio, blog y tiendas en línea (cotización aparte)
- 💬 Botón directo a WhatsApp
- 🌗 Modo claro y oscuro
- 📐 Diseño responsive
- 📝 Formulario de cotización

## 🛠️ Stack

- 🧑‍🚀 [Astro](https://astro.build)
- 🎨 [Tailwind CSS v4](https://tailwindcss.com)
- 🔤 Fuentes: Inter (texto) y Space Grotesk (títulos)
- ☁️ Hosting: Netlify

## 📁 Estructura

```text
/
├── public/
├── src/
│   ├── components/
│   ├── layouts/
│   ├── pages/
│   └── styles/
└── package.json
```

## 🧞 Comandos

| Comando            | Acción                                        |
| :----------------- | :-------------------------------------------- |
| `pnpm install`     | 📦 Instala las dependencias                   |
| `pnpm dev`         | 💻 Servidor local en `localhost:4321`         |
| `pnpm build`       | 🏗️ Genera el sitio de producción en `./dist/` |
| `pnpm preview`     | 👀 Previsualiza el build antes de publicar    |
